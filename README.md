# 🌤 Clima Weather App

**Clima Weather App** is a responsive and interactive web application that provides **real-time weather updates** for cities worldwide. Built with **React.js** and **Vite**, it fetches live weather data from a reliable API and displays it in a clean, user-friendly interface.  

---

## 🌟 Features
- **Real-Time Weather:** Get current temperature, humidity, wind speed, and weather conditions.  
- **City Search:** Search for any city worldwide to see instant weather updates.  
- **Dynamic Weather Icons:** Intuitive icons representing different weather conditions.  
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile screens.  
- **Dynamic Backgrounds:** Background changes according to weather conditions for immersive visuals.  

---

## 🛠 Technologies Used
- **Frontend:** React.js, Vite, CSS3  
- **API:** OpenWeatherMap API  
- **Icons:** React Icons  

---

## 🚀 Installation
1. Clone the repository:  
```bash
git clone https://github.com/Aditya11376/Clima-weather-app.git
```

2. Navigate to the project directory: 
```bash
cd Clima-weather-app
```

3. Install dependencies: 
```bash
npm install
```

4. Start the development server:
```bash
npm run dev
```

5. Open the provided localhost URL in your browser to use the app.
